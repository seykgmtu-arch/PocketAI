# PocketAI 0.2.0 — Milestone 2

Распакуйте переносную сборку целиком и запустите PocketAI.exe.

- **Модели:** положите GGUF в models/chat, обновите список, выберите модель и нажмите кнопку применения. Выбор сохраняется только после успешного запуска. При ошибке приложение пытается восстановить предыдущую модель.
- **База знаний:** добавляйте TXT, MD, CSV, JSON, LOG, CS и DOCX. Индекс хранится локально в knowledge/index.json. Поиск v1 основан на совпадении слов; найденные фрагменты передаются только локальному llama-server. Очистка индекса не удаляет исходные документы.
- **Диагностика:** ZIP создаётся в diagnostics. Включает аппаратные параметры, размеры моделей, числовые настройки, наличие runtime, сводку логов и ограниченное дерево файлов. Сырые логи, промпт, произвольные имена файлов, пути пользователя и содержимое документов/моделей исключены. Отправка в ChatGPT вручную; автоматической отправки нет.

Перед обновлением существующей установки сохраните свою pocketai.json, models и knowledge. Поставляемая pocketai.json содержит настройки по умолчанию. Для первой проверки лучше распаковать новую версию в отдельную папку.

Windows CI проверяет сборку, семь форматов документов, повторный/неудачный импорт, сохранение и очистку индекса, поиск, каталог моделей, сохранение конфигурации, загрузку XAML и отсутствие тестовых секретов в диагностике. Затем выполняется реальный CPU-запрос через PocketAI.exe. CUDA-выполнение на GitHub runner не проверяется.
